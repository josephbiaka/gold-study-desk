# Jay's Trading Study Desk

Study tools for COMEX micro gold (MGC) futures and Nasdaq-100 (NQ/MNQ) futures, plus a trade journal.

| File | What it is |
|---|---|
| `index.html` | The Study Desk: tabs for all the study tools below |
| `mindset.html` | Morning Mindset: Mark Douglas's five fundamental truths and seven principles of consistency ("I am a consistent winner because…"), to read before trading. Opens first each day until marked read |
| `checklist.html` | My Trading MGC/MNQ Checklist 2026: clickable pre-trade checklist with a trade plan that works out risk-to-reward and account risk. Ticks reset each day |
| `lab.html` | Gold Futures Lab, a 12-step course |
| `nasdaq.html` | Nasdaq Futures Lab, a 9-step fundamental-analysis course for NQ/MNQ (valuation & rates, earnings, Fed, intermarket, sentiment, weekly scorecard) |
| `dale.html` | Trader Dale order-flow Q&A trainer (207 questions). Page references are the page numbers printed in each book; the PDF viewer adds each book's front-matter offset |
| `pa.html` | Trader Dale price action setups questionnaire (62 questions across 12 setups, with page references) |
| `candles.html` | Candlestick pattern drills |
| `fvg.html` | Fair value gap drills |
| `smt.html` | SMT divergence: Gold vs Silver (GC/SI) and Nasdaq vs S&P (NQ/ES), 8 setups, session times and chart drills |
| `journal.html` | Micro Gold Journal (Topstep 150K rules). Saving trades only works on the claude.ai version. |

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).

Education only, not financial advice.
